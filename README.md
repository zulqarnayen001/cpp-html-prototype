# The CPP and Me: HTML prototype

JA Canada's The CPP and Me course, rebuilt in plain HTML, CSS and JavaScript (no Storyline), with a phone layout for
every slide. Prototype for internal review; the live course is on JA Campus.

- Start page: `index.html` (open the course, see it at phone sizes, compare with the Storyline version)
- The course: `course/index.html`
- Phone sizes side by side: `course/phone-preview.html`

Built from `CPP\Dev\CPP_HTML_Prototype` with `tools/build_github_pages.py`. Not indexed by search engines.
